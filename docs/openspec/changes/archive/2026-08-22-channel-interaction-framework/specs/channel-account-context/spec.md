## Purpose

消息平台账户上下文定义能力执行时的身份与归属边界：权益（会员、余额、签到记录等）挂在消息平台账户（消息平台 + 外部用户 id）上，不做跨消息平台账户合并；为后续计费/会员/签到能力提供统一执行上下文。

## ADDED Requirements

### Requirement: 消息平台账户执行上下文
能力调用 MUST 携带消息平台账户上下文（channel_id + external_user_id + 内部用户 id），业务能力据此读写归属该消息平台账户的权益数据；不同消息平台的同一自然人视为不同消息平台账户。

#### Scenario: 能力读取消息平台账户权益
- **WHEN** 某能力执行且需要权益上下文
- **THEN** 上下文提供当前消息平台账户标识，权益读写限定于该消息平台账户

#### Scenario: 跨消息平台账户隔离
- **WHEN** 同一自然人在两个消息平台各有一个消息平台账户
- **THEN** 各自的权益数据互不影响，不自动合并

### Requirement: 权益数据归属
系统 MUST 以消息平台账户为权益归属键（消息平台 + 外部用户 id，或对应的内部用户 id）；权益表结构 MUST 允许按消息平台账户查询与更新。

#### Scenario: 按消息平台账户记录权益
- **WHEN** 签到/充值等能力写入权益
- **THEN** 记录归属当前消息平台账户，可被同一消息平台账户后续查询
