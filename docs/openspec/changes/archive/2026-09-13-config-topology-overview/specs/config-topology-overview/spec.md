## Purpose

在管理后台用只读配置拓扑图展示消息平台、工作流、任务队列、计算节点之间的挂载与派发关系，并在节点上复用同一套健康结论。

## ADDED Requirements

### Requirement: 四层配置拓扑
系统 MUST 将配置关系画成四层：消息平台 → 工作流 → 任务队列 → 计算节点。最左一层 MUST 一个消息平台一个节点。MUST NOT 把菜单入口画成独立节点。连线 MUST 表示：平台经菜单挂到工作流、工作流路由到任务队列、计算节点订阅该队列。

#### Scenario: 平台挂到工作流
- **WHEN** 某消息平台的菜单把一个工作流挂上
- **THEN** 图上该平台与该工作流之间有一条连线，且没有菜单入口节点

#### Scenario: 工作流路由到队列
- **WHEN** 某工作流的处理流程把任务派到某个任务队列
- **THEN** 图上该工作流与该队列之间有一条连线

#### Scenario: 节点订阅队列
- **WHEN** 某计算节点订阅某个任务队列
- **THEN** 图上该队列与该节点之间有一条连线

### Requirement: 全局图不画孤立资源
工作台全量图 MUST 只包含至少有一条连线的资源。没有任何连线的工作流、任务队列、计算节点或消息平台 MUST NOT 出现在全量图上。

#### Scenario: 未挂载且无路由的工作流
- **WHEN** 某工作流没有菜单挂载，也没有路由到任何任务队列
- **THEN** 工作台全量图不出现该工作流

#### Scenario: 已路由的工作流即使缺入口仍出现
- **WHEN** 某工作流没有菜单挂载，但已路由到任务队列
- **THEN** 工作台全量图出现该工作流及其下游连线

### Requirement: 节点健康与链路健康一致
每个图节点 MUST 使用与对应详情页链路健康相同的结论：无问题为绿色，任一问题为黄色。健康数据仍在加载、失败或缺失时 MUST NOT 显示绿色。MUST NOT 使用红色档位。

#### Scenario: 详情页有问题则图上为黄
- **WHEN** 某工作流详情的链路健康为存在问题
- **THEN** 拓扑图上该工作流节点为黄色

#### Scenario: 健康未就绪不标绿
- **WHEN** 组装拓扑所需的健康输入尚未就绪
- **THEN** 相关节点不显示绿色正常

### Requirement: 点选高亮路径而不跳转
点选图上某一节点时，系统 MUST 高亮所有经过该节点的路径上的节点与连线，并降低其余元素的视觉权重。MUST NOT 因这次点选离开当前页或关闭弹窗。系统 MUST 同时提供「打开详情」动作；仅当运维点该动作时才进入对应资源详情。

#### Scenario: 点选队列高亮上下游
- **WHEN** 运维点选某个任务队列节点
- **THEN** 经过该队列的平台、工作流、队列、节点路径被高亮，页面仍停留在工作台或当前弹窗

#### Scenario: 打开详情才跳转
- **WHEN** 运维在已点选的节点上点「打开详情」
- **THEN** 进入该资源的详情页

### Requirement: 只读画布
拓扑图 MUST 可平移、缩放以看清全貌。MUST NOT 允许拖拽改位置并持久化，MUST NOT 允许在图上新增、删除或改写连线。

#### Scenario: 缩放不改配置
- **WHEN** 运维缩放或平移画布
- **THEN** 菜单挂载、工作流路由与节点订阅均不发生变化

### Requirement: 工作台全量卡片
工作台 MUST 在左栏用一张卡片展示全量配置拓扑，卡片内直接铺画布。该卡片 MUST 可独立加载与失败隔离，失败时仅该卡片进入错误态。

#### Scenario: 打开工作台看到拓扑卡片
- **WHEN** 运维打开工作台且拓扑数据可用
- **THEN** 左栏出现内含画布的配置拓扑卡片

#### Scenario: 拓扑数据失败不影响其他卡片
- **WHEN** 组装拓扑所依赖的某一请求失败
- **THEN** 仅拓扑卡片进入错误态，工作台其余区块仍可展示

### Requirement: 详情弹窗看过当前资源的路径
工作流、消息平台、任务队列、计算节点详情 MUST 提供打开拓扑的入口。弹窗 MUST 只包含当前资源，以及所有经过它的路径上的节点与连线。若当前资源没有任何连线，弹窗 MUST 仍包含该资源自身，且没有连线。

#### Scenario: 从工作流打开弹窗
- **WHEN** 运维在某工作流详情打开拓扑
- **THEN** 弹窗画出该工作流、挂到它的消息平台、它路由到的队列、以及订阅这些队列的计算节点，不包含与它无关的其他工作流

#### Scenario: 当前资源没有连线
- **WHEN** 运维从没有任何挂载与路由的工作流打开拓扑
- **THEN** 弹窗中只有该工作流节点，没有连线
