# 列表 / 详情布局方案库

供后续 change 再选；**本 change（admin-web-console）采用 B**。

交互对照 Canvas（可选）：仓库外 Cursor canvas `admin-list-detail-layouts.canvas.tsx`。

## A — 经典表 + 整页详情

- 列表：顶栏筛选 + Data Table；行点击进详情
- 详情：独立路由整页；顶栏标题/状态/操作；下方分区块
- 适合：字段多、要扫很多行；五资源统一最省事
- 日常：列表与详情分页逛；返回靠后退/面包屑

## B — 左右分栏 Master–Detail（本期选用）

- 列表：左窄列 ID/状态/关键字段；选中高亮
- 详情：同屏右侧即时刷新；窄屏可降级为整页
- 适合：Task/Session 快翻；本期统一五资源 + Case 右侧可滚动分段表单
- 日常：点一下就看详情，少跳页

## C — 卡片网格 + 右侧抽屉

- 列表：响应式卡片（名称、标签、启用态、短描述）
- 详情：右侧 Sheet/Drawer；可再「全屏编辑」
- 适合：Case 浏览、实例概览
- 日常：先扫卡片再拉开；重编辑进全页

## D — 高密度运维台

- 列表：紧凑表 + 行内快捷（启停/取消）；等宽 ID
- 详情：粘性操作条 + Tabs（概要/观测/JSON）
- 适合：实例观测、Task 取消、批量扫状态
- 日常：许多操作不用进详情

## E — 文档式详情 + 简易列表

- 列表：单列清单，弱化表格线
- 详情：左侧目录锚点 + 右侧长文分段
- 适合：Case 结构化多段编辑
- 日常：改配置像改说明书
