## Purpose

用飞书企业自建应用的长连接，在本机收消息、用卡片调用已有工作流，并把成品图发回飞书；不要求给 Pixoma 配公网 URL。

## ADDED Requirements

### Requirement: 长连接收事件
系统 MUST 使用飞书企业自建应用的 WebSocket 长连接接收消息与新版卡片回调。MUST NOT 要求配置公网事件 URL。商店应用长连接不在本期。收到事件后 MUST 在平台时限内完成应答（不得把 Comfy 出图放在回调线程里跑完）。

#### Scenario: 无公网 URL 能收私聊
- **WHEN** 已启用飞书消息平台且本机长连接在线，用户向该机器人发私聊文本
- **THEN** 系统收到该事件并应答成功，无需公网回调地址

#### Scenario: 出图不堵在回调里
- **WHEN** 用户触发需要 Comfy 出图的工作流
- **THEN** 事件回调在出图完成前已经成功返回；成品稍后通过发消息 API 送达

### Requirement: 卡片打开工作流并回图
飞书侧 MUST 能列出或点选已启用工作流、采集输入（含图片）、ConfirmRun 后把图片消息发回原会话。群里 @ 机器人 MUST 可走同一执行链，结果发回该群。

#### Scenario: 私聊出图
- **WHEN** 用户在飞书私聊打开已启用工作流并提交足够输入
- **THEN** 该私聊收到成品图片（或等价媒体）

#### Scenario: 群 @ 出图回群
- **WHEN** 群成员 @ 机器人并成功跑完带图输出的工作流
- **THEN** 该群收到成品图
