## Purpose

管理端在渠道详情里用可视化编辑器编排 Telegram 主键盘和卡片消息：画布就是手机，积木是键盘按钮和卡片，保存的是一棵嵌套树。

## ADDED Requirements

### Requirement: 手机画布即用户所见
渠道菜单编辑器 MUST 以手机形态画布为中心：运营在画布上看到的主键盘格子和卡片消息，MUST 与用户在 Telegram 中将看到的结构一致（列数、按钮文案、卡片正文/媒体、卡片按钮）。编辑器 MUST NOT 再提供与画布脱节的「卡片库」平铺管理。

#### Scenario: 打开编辑器看到手机
- **WHEN** 运营进入某渠道的菜单编辑
- **THEN** 中间是手机画布，默认展示该渠道主键盘（含列数与按钮文案）

#### Scenario: 打开卡片时画布切到卡片
- **WHEN** 运营在画布上进入一张卡片节点
- **THEN** 手机画布展示该卡片的媒体、正文和底部按钮，而不是另一套网页表单页

### Requirement: 调色板只提供菜单积木
编辑器调色板 MUST 只提供菜单相关积木：主键盘按钮、卡片、卡片按钮，以及按钮可绑定的动作类型。MUST NOT 提供网页表单字段（如邮箱输入、日期选择）作为可保存节点。

#### Scenario: 拖入键盘按钮
- **WHEN** 运营从调色板把「键盘按钮」拖到主键盘
- **THEN** 画布上出现新按钮，属性面板可改文案并选择动作

#### Scenario: 表单字段不在调色板
- **WHEN** 运营查看调色板
- **THEN** 看不到用于网页表单的 Input/Select/Checkbox 一类积木

### Requirement: 打开卡片即挂子树
当按钮动作是打开卡片时，该卡片 MUST 作为该按钮的子节点出现在同一棵树上，可在画布中继续编辑。MUST NOT 用独立卡片 id 库做跨按钮复用。

#### Scenario: 按钮下挂一张新卡片
- **WHEN** 运营把某键盘按钮的动作设为打开卡片并新增卡片
- **THEN** 该卡片只挂在这个按钮下；从画布删除该按钮后，这张卡片一并消失

#### Scenario: 卡片按钮再挂卡片
- **WHEN** 运营在卡片按钮上再次选择打开卡片
- **THEN** 新卡片作为该按钮的子节点可继续编辑，用户路径为逐层打开卡片消息

### Requirement: 动作参数只显示当前类型所需字段
按钮属性面板 MUST 按当前动作类型只展示必要字段：打开工作流需选择已有工作流；发文字/复制需文本；发媒体需媒体地址；打开链接需 http(s) URL；打开卡片编辑子卡片而不是另选卡片库。切换类型时面板 MUST 换成对应字段。

#### Scenario: 切到打开工作流
- **WHEN** 运营将动作改为打开工作流
- **THEN** 只出现工作流单选，不出现 URL、媒体列表或卡片库下拉

#### Scenario: 非法动作不能保存
- **WHEN** 运营保存时某按钮缺少该动作类型的必填内容（如打开工作流未选工作流、打开链接不是 http(s)）
- **THEN** 保存被拒绝并指出问题位置，已保存文档不被破坏

### Requirement: 详情只读、编辑整页
渠道详情 MUST 用与编辑器相同的手机渲染只读展示当前已保存树，MUST NOT 再展示能力地图。进入编辑 MUST 打开独立整页（左调色板、中手机画布、右属性），MUST NOT 把 Puck 塞进详情弹层。整页 MUST 能返回详情；有未保存修改时返回走「未保存离开有确认」。

#### Scenario: 详情只看到只读手机
- **WHEN** 运营打开渠道详情且不进入编辑
- **THEN** 菜单区域是只读手机预览（主键盘或可点进的只读卡片），没有可拖拽调色板，也没有能力地图

#### Scenario: 编辑打开整页
- **WHEN** 运营在详情点击编辑菜单
- **THEN** 进入整页编辑器，可见调色板、手机画布与属性面板；保存成功后回到详情，只读手机与刚保存的树一致

### Requirement: 保存整棵树
编辑器保存 MUST 提交该渠道完整菜单树；成功后再次打开 MUST 看到同一棵树。空树（无任何键盘按钮）MUST 被拒绝，除非产品明确允许空键盘——本期 MUST 至少保留一个合法键盘按钮，或回落到系统默认树（由配置能力规定），二者不得静默丢数据。

#### Scenario: 保存后重开一致
- **WHEN** 运营保存一棵合法树并重新打开编辑器
- **THEN** 手机画布与属性与保存前一致

#### Scenario: 未保存离开有确认
- **WHEN** 运营有未保存修改并关闭编辑器
- **THEN** 系统提示未保存，确认前不丢弃也不得悄悄写库
