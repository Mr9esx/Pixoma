## Purpose

用企业微信智能机器人的本机长连接，让人在私聊或群 @ 里调用已有工作流并收回成品图，不必给 Pixoma 配公网回调 URL。

## ADDED Requirements

### Requirement: 智能机器人长连接
系统 MUST 以 Bot ID 与 Secret 建立一条 WebSocket 长连接并订阅消息。MUST NOT 要求配置接收消息的公网 URL 或企业可信 IP。同一消息平台实例同一时刻 MUST 只有一条活动长连接。

#### Scenario: 无公网回调能收私聊
- **WHEN** 已启用企微智能机器人消息平台且长连接在线，成员向该机器人发私聊
- **THEN** 系统收到消息，无需公网回调地址

#### Scenario: 热重载不双连
- **WHEN** 管理员更新 Secret 导致适配器重建
- **THEN** 旧连接先关闭，再建立新连接；不得长时间两条 WSS 并存

### Requirement: 卡片或欢迎语打开工作流并回图
系统 MUST 能在进会话或对话中提供已启用工作流入口，采集输入后 ConfirmRun，并把图片发回原会话。群里 @ 机器人 MUST 可触发；结果 MUST 发回该群。出图超过平台流式时限时 MUST 改用主动推送，不得丢图。

#### Scenario: 私聊出图
- **WHEN** 成员在企微私聊打开已启用工作流并提交足够输入
- **THEN** 该私聊收到成品图

#### Scenario: 群 @ 出图回群
- **WHEN** 群成员 @ 机器人并成功跑完带图输出的工作流
- **THEN** 该群收到成品图

#### Scenario: 超时后仍能投递
- **WHEN** Comfy 出图超过智能机器人流式窗口
- **THEN** 系统仍把成品发到原会话（主动推送），不因流式超时丢失
