## Why

Pixoma 需要一个可公开访问的 Live Demo，让访客在部署前完整浏览后台能力，同时保证不会写入真实业务数据、不会暴露真实节点，也不会触发外部副作用。

## What Changes

- 新增启动参数 `-livedemo`，启用进程内只读演示模式。
- Live Demo 使用固定的演示管理员账号 `admin / 123456`，并在登录页醒目提醒。
- 启动时注入内存中的演示数据，例如演示节点、案例、任务、用户、频道、话题和统计；数据只存在于当前进程。
- 屏蔽设置菜单入口和设置相关 API，禁止进入初始化向导或修改运行配置。
- 屏蔽密码修改等敏感账号 API，禁止注册、创建、编辑、删除和其他写操作。
- **BREAKING**：Live Demo 模式是部署与展示专用模式，不提供数据持久化与真实运行能力。

## Capabilities

### New Capabilities

- `readonly-live-demo-mode`: 定义 `-livedemo` 启动隔离、固定演示账号、演示数据、只读拦截、设置入口屏蔽和敏感接口保护。

### Modified Capabilities

## Impact

- 影响 `apps/pixoma/cmd/pixoma` 的启动链路与后台 HTTP 路由装配。
- 影响登录页、后台导航/设置入口的前端状态展示。
- 需要新增或适配内存演示仓储与演示数据集。
- 不改变常规启动模式、既有数据结构和正常部署流程。
