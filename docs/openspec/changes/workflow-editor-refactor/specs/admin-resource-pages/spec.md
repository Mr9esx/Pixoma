## ADDED Requirements

### Requirement: Case 编辑使用统一工作流编辑组件
Case 创建/编辑页 MUST 使用统一工作流编辑组件承载「基础信息 + 导入 + 输入 + 输出」；其基础信息预览字段 MUST 支持直接上传图片/视频并内嵌预览。

#### Scenario: 预览字段可直接上传媒体
- **WHEN** 运维在 Case 创建/编辑页的基础信息选择本地上传图片或视频
- **THEN** 系统上传并内嵌预览，保存后随 Case 持久化

#### Scenario: 输入输出沿用统一交互
- **WHEN** 运维在 Case 创建/编辑页编辑输入输出
- **THEN** 使用与向导第一步一致的一键生成与内联绑定交互
