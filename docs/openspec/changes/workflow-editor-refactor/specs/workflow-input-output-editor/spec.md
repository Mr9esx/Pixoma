## ADDED Requirements

### Requirement: 统一工作流编辑组件
工作流配置（导入 JSON + 基础信息 + 输入 + 输出）MUST 收敛为单一可复用编辑组件，被独立编辑页与 Quick Config 第一步共同消费；对输入/输出与预览的任何改动 MUST 在该组件单点生效，两端行为一致。

#### Scenario: 独立编辑页使用统一组件
- **WHEN** 用户在独立的工作流创建/编辑页配置输入输出与预览
- **THEN** 页面由统一编辑组件渲染，交互与 Quick Config 第一步一致

#### Scenario: 向导第一步使用同一组件
- **WHEN** 用户在 Quick Config 第一步配置工作流
- **THEN** 第一步复用同一编辑组件，输入/输出与预览交互与独立编辑页一致

### Requirement: 输入字段一键生成
编辑页 MUST 提供「一键生成」：在导入合法工作流 JSON 后，把图中全部字面量参数生成输入字段草稿、全部输出槽位生成输出字段草稿；生成的字段类型 MUST 基于节点类型自动推断，用户可在此基础上增删改。

#### Scenario: 导入后一键生成输入
- **WHEN** 导入合法 JSON 后用户触发「一键生成」
- **THEN** 系统按图中字面量参数生成输入字段草稿，类型自动推断并可选绑定

#### Scenario: 导入后一键生成输出
- **WHEN** 导入合法 JSON 后用户触发「一键生成」
- **THEN** 系统按全部输出槽位生成输出字段草稿，类型自动推断

#### Scenario: 生成后可增删改
- **WHEN** 生成字段草稿后用户删除多余字段或修改类型/必填
- **THEN** 编辑结果随表单保存持久化

### Requirement: 表格化批量编辑
宽屏场景下输入/输出字段 MUST 支持以表格行批量编辑（key/类型/必填/描述/绑定各为一列），新增与删除以行操作完成；窄屏 MUST 降级为字段卡片布局。

#### Scenario: 宽屏表格编辑输入
- **WHEN** 屏幕宽度满足宽屏阈值且存在输入字段
- **THEN** 输入字段以表格行展示，逐列可编辑，可整行删除

#### Scenario: 窄屏卡片布局
- **WHEN** 屏幕宽度小于宽屏阈值
- **THEN** 输入/输出回退为字段卡片布局，功能与表格等价

### Requirement: 内联绑定交互
字段绑定 MUST 提供比逐字段弹层更短的路径：点击行内「绑定」后，在侧栏列出该字段对应节点可绑参数/输出，点选即完成绑定并回填；MUST 保留现有类型自动判断。

#### Scenario: 点选即绑定输入
- **WHEN** 用户对某输入字段打开内联绑定
- **THEN** 侧栏展示该节点可绑字面量参数，点选即完成绑定并关闭

#### Scenario: 点选即绑定输出
- **WHEN** 用户对某输出字段打开内联绑定
- **THEN** 侧栏展示可选输出槽位，点选即完成绑定并回填类型

#### Scenario: 未绑定字段校验
- **WHEN** 提交时仍有输入字段未绑定节点与参数
- **THEN** 校验阻止保存并定位到对应字段
