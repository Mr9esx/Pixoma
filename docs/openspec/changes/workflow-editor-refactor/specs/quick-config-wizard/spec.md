## ADDED Requirements

### Requirement: 第一步复用统一工作流编辑组件
Quick Config 第一步（工作流配置）MUST 复用与独立编辑页相同的统一工作流编辑组件；该步骤的输入/输出与预览交互 MUST 与独立编辑页保持一致，改动在组件单点生效。

#### Scenario: 第一步输入输出交互一致
- **WHEN** 用户在向导第一步中添加输入/输出字段
- **THEN** 展示的交互（一键生成、内联绑定、媒体预览）与独立编辑页一致

#### Scenario: 组件单点生效
- **WHEN** 工作流编辑组件在某入口得到增强或修复
- **THEN** 向导第一步与独立编辑页同时生效，无需分别改动
