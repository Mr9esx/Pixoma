# Admin 圆角规范

适用范围：`web/admin` 的页面、浮层和交互组件。按容器在页面中的作用选择圆角；并列且作用相同的容器使用同一尺寸。

- **16px（`rounded-2xl`）**：页面主体面板、大型工作区、`Dialog`、`AlertDialog`。
- **10px（`rounded-lg`）**：完整内容区块、按钮、输入框、选择器、浮层及内部节点，包括 `Card`、带外框的表格、图表查看器和文件附件。
- **6px（`rounded-sm`）**：菜单选项、小标签、checkbox 等紧凑元素。
- **`rounded-full`**：头像、状态点、进度条和胶囊形控件。贴合父容器边缘的内容使用 `rounded-none`。

工作流详情页的输入表格、输出表格、节点图查看器和内部节点卡片都使用 10px；详情页主体面板使用 16px。

页面代码使用 Tailwind 圆角类，不写固定像素圆角。现有 shadcn 组件仍有 `rounded-md` 类，主题将其映射到 10px；新增控件优先使用 `rounded-lg`。设备外观、图表标记等形状可以使用与其用途相符的尺寸。
