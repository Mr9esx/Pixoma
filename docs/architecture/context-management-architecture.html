Pixoma Context Management Architecture

只保存一次 · 统一回放 · 超限压缩 · 失败可恢复

不可变事实层

  • • 原始消息、工具组、Run 事件永久保留
  • • Compaction 只追加记录，不覆盖历史
  • • 每条记录有稳定顺序和边界 ID

模型上下文层

  • • Context Compiler 是 Agent 唯一入口
  • • 摘要覆盖全部被移除内容
  • • 切点只落在完整轮次或工具组

可恢复性

  • • 超长、摘要失败、数据库失败都有状态
  • • 失败不产生半成品 compaction
  • • UI、Trace、Agent 使用同一回放语义
