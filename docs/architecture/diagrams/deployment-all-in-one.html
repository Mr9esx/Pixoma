Pixoma · All-in-One 部署

最小依赖 · 单进程即可跑通全套生成链路 — 一个二进制，零外部基础设施

零外部依赖

  • • 单进程编排控制面与执行面，不依赖 Redis
  • • 默认进程内内存事件总线，无独立 MQ
  • • 嵌入式 SQLite + LocalFS，数据零运维

一条命令启动

  • • docker run 单个二进制即可跑通全套生成链路
  • • 除 Telegram 与 ComfyUI 外无需任何服务
  • • 适合本机、自托管、内网与私有化交付

平滑升级路径

  • • SQLite → MySQL/Postgres，仅换适配器
  • • LocalFS → S3/TOS，对象存储无缝切换
  • • Memory → NATS，业务代码与限界不改变
