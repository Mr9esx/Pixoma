Pixoma System Architecture

同一套「干活的」：要么塞进 Bot，要么单独开进程（edge-agent）

大脑（Bot）

  • • 跟用户说话、建任务
  • • 把材料打成任务包放仓库
  • • 发「去干这个」小纸条
  • • 云+家里时：看干活的在不在

中间货架

  • • 队列：只传小纸条
  • • 仓库：任务包和大图
  • • 两种跑法只换「货架用啥」

干活的（Worker）

  • • 就是 Actuator；外置时叫 Edge
  • • 取包 → 调本机 Comfy → 回传
  • • 差别只是进程住哪，不是两套逻辑
