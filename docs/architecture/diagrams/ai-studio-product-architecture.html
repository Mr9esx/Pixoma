Pixoma Studio · AI Chat Agent

Session 是创作工作区，Asset 是可复用上下文与产物，Agent 负责协调模型、工作流、Skill 与 MCP；Flow 负责把执行过程变成可理解、可审批、可恢复的用户界面。

01 价值链02 能力图谱03 分层架构04 运行时闭环

01 / 产品价值链

从自然语言意图到可复用资产，价值不止发生在单次回复。

02 / 能力图谱

产品入口保持简单，Agent 将底层异构能力统一成可观察的 Run 与 Asset。

03 / 分层技术架构

Studio 作为独立领域建设；只通过稳定适配器连接现有工作流与 MCP Server。

04 / 运行时闭环

命令写入服务端后立即具备恢复能力；浏览器只订阅状态，不持有任务生命周期。

前端策略

  • • assistant-ui 负责标准 Chat 交互
  • • React Flow 负责 Pixoma 执行可视化
  • • 服务端快照是真实状态来源

领域边界

  • • Studio 不复用旧 Bot / MCP 内部实现
  • • Workflow 与 MCP 仅通过 Adapter 接入
  • • Asset 是独立一等领域对象

可靠性原则

  • • Run 在服务端持久化并后台执行
  • • 事件有序、幂等、可重放
  • • 资产固定版本，历史输入不漂移
