PIXOMA STUDIO AGENT / RUNTIME ARCHITECTURE

从 Studio 消息到 Eino 单 Agent、工具执行、审批恢复与持久化事件的当前代码路径

Run 生命周期

  • 消息与 Run 先保存，再进入后台队列。
  • 创建 Run 时保存已启用 Skill 快照；系统提示词提供名称与描述，load_skill 按需读取完整 Prompt。
  • 运行事件按序保存，AG-UI 支持游标续传。

审批恢复

  • 工具策略要求批准时，Eino 产生 Interrupt。
  • 审批与 Checkpoint 保存后，Run 等待用户决定。
  • 批准后由 Runner 重新排队，Engine 从 Checkpoint 恢复。

代码边界

  • AgentEngine 通过 DispatchEngine 调用 Eino Engine。
  • 工具经 AgentSink 写入消息、事件、资产与 Flow。
  • Workflow 与 MCP 分别经专用 Runtime Adapter 接入。

颜色说明

  • 青色：Studio 调用端与 AG-UI 接口。
  • 绿色：应用服务与 Agent Runtime。
  • 紫色：持久化；玫瑰色：审批；琥珀色：外接能力。
