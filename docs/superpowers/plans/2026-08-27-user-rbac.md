# 用户 + RBAC 实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: 使用 superpowers:subagent-driven-development（推荐）或 superpowers:executing-plans 逐任务实现。步骤用 checkbox（`- [ ]`）跟踪。

**Goal:** 在 Pixoma 后台引入控制台系统账号体系与 RBAC（Admin/Operator/Viewer），支持首启向导「如何称呼您」资料步骤、系统设置「用户管理」、系统设置「是否开放注册」开关与自助注册；并把渠道终端用户表更名为 `channel_users`。

**Architecture:** 新增 `ConsoleUser` Domain + `console_users` 表承载登录账号；登录/会话升级为「账号 id + 角色」；`adminhost.Gate` 后叠加 RBAC 权限点校验；用户管理/注册走新 `adminusers`、`auth` 包；向导插入 profile 步骤。渠道用户表经 `db.RenameLegacy` 幂等更名。

**Tech Stack:** Go (chi/gorm/sqlite/mysql/postgres, bcrypt), React/TanStack + Vite + Vitest（contract 测试）。

## Global Constraints

- 语言与文案使用中文（zh-CN），沿用既有 `*.contract.test.ts` 契约测试模式。
- 密码 ≥8 位，bcrypt 存储；列表/详情接口不返回 `password_hash`。
- 不新增第三方依赖；不改变既有业务接口路径。
- 账号/角色/删除类接口仅 `Admin`；未认证 401、越权 403、注册关闭 409。
- 遵循 TDD：先写失败测试，再实现，后提交。
- 代码审查 `standard`；每任务提交一次，commit 信息说明变更原因。
