# Pixoma Studio 项目资产库 PRD

## 1. 背景与目标

Studio 已有项目和 Session 的归属关系。当前 Session 创建的资产与资产库记录分别管理，创作者需要手动把 Session 资产存入资产库。资产库仍按账号展示，无法按项目查看创作产物；详情也缺少评分、图片尺寸与时间信息。

资产库改为 Studio 资产的统一目录。Session 中创建并保存的文件自动出现在资产库，按所属项目整理；Session 资产面板展示同一份资产数据，并按来源 Session 筛选。资产库保留来源、固定版本和跨 Session 引用关系。

交付结果以三个任务判断：

- 对话生成、手动创建或上传资产后，在对应项目资产库立即找到该资产及其来源。
- 能通过分类、标签、评分、搜索、筛选与排序找到资产。
- 能跨 Session 使用资产的固定版本，批量整理、导出资产，并识别内容完全相同的文件。

## 2. 适用对象与典型任务

- 创作者在「雨夜侦探漫画」项目中查看所有 Session 生成的角色图，把固定版本用于同项目的新 Session。
- 运营人员向指定项目上传参考图，添加标签和评分，再按格式、尺寸与时间查找。
- 工作流产出多张图片后，资产自动出现在项目资产库，创作者批量归类并检查重复文件。
- 创作者把资产用于另一项目时，目标项目出现对应资产条目，两个项目各自管理分类、标签和展示名称。
- 创作者核对原文件、版本、来源对话和时间信息后，导出采用的文件。

## 3. 资产归属与统一目录

- Studio 左栏保留「资产库」入口。资产库页面左侧常驻项目资产树，默认层级为「项目 → 资产」，其中包含「未归属项目」。树标题旁提供设置按钮，可切换「项目 → 资产 / 对话 / 分类 / 格式 / 评分 / 标签」六种组织方式。项目节点显示资产数量，可展开或收起；点击项目节点在右侧展示该项目资产。从某个项目或 Session 进入时选中所属项目。
- `Asset` 表示内容身份，`AssetVersion` 表示不可变的文件版本。`ProjectAsset` 表示某个项目中的资产条目，记录展示名称、分类、标签、评分、添加时间、归档状态和固定的 `AssetVersion`。同一 `Asset` 可出现在多个项目中，文件内容只保存一次。
- `SessionAssetUsage` 记录来源或引用关系，包括 Session、AssetVersion、用途和产生操作。Session 资产面板按来源或使用关系读取统一目录，不再创建另一套资产列表。
- Session 生成的文件、手动创建的文档和在 Session 中上传的文件，一旦保存 `AssetVersion`，就与当前 Session 的项目资产条目一同写入。没有项目的 Session 对应「未归属项目」。从资产库上传时使用左侧资产树当前选中的项目，包括「未归属项目」。
- 在另一个项目的 Session 使用资产时，为目标项目建立指向所选固定版本的资产条目；已有目标项目条目时复用它。源项目条目的分类、名称、标签和评分保持原值。Session 引用始终保存具体版本 ID。
- 所有查询和操作校验账号对项目的归属。来源 Session 不可访问时，资产及已保存的来源信息仍可读取。

### 3.1 项目变更

- 把 Session 移到另一项目时，为其创建、上传和引用的资产在目标项目建立条目；原项目条目继续保留。两个项目中的整理信息分别保存，来源仍指向原 Session。
- 删除项目时，项目下的 Session 和资产条目转入「未归属项目」。原有分类在「未归属项目」下按原项目名称成组保存；同名分类增加可辨识后缀。目标位置已有同一资产条目时保留目标条目的整理信息与固定版本，来源项目条目的版本仍可在版本历史中查看。删除确认弹窗显示受影响的 Session、资产和分类数量。
- 删除 Session 不删除资产或文件版本。资产详情保留来源快照，并在来源对话不可访问时明确显示该状态。
- 「归档」只改变项目资产条目的显示状态；已归档资产仍可在项目资产库中筛选和恢复，历史 Session 引用继续有效。

## 4. 信息结构

资产库页面由五个区域组成：

1. Studio 上下文侧栏：切换 Session 与资产库。
2. 左侧项目资产树：固定展示项目及所选组织方式对应的节点；设置按钮切换六种树结构，项目节点显示资产数量。
3. 顶部分类栏：在原资产类型切换位置展示当前项目的全部资产、未分类和分类选项；提供新建、改名入口。
4. 资产区：资产类型与格式下拉选择、搜索、来源 Session、其他条件、排序、网格或列表、批量操作。
5. 详情弹窗：预览、项目、来源 Session、名称编辑、标签、评分、基本信息、图片或视频调色盘、版本与文件操作。

桌面宽屏中，项目资产树固定在资产区左侧并单独滚动，切换筛选和详情时保持展开状态。默认树在项目层级下直接展示资产；未增加中间文件夹层级。项目节点数量统计该项目未归档资产，展开后按最近添加显示资产节点；资产节点逐段加载，长列表只渲染当前可见部分。切换组织方式保留当前项目和展开状态，并清除原组织方式的节点选择。右侧筛选只影响资产区结果，资产树仍展示当前账号可访问的项目资产。「未归属项目」使用相同结构。窄屏时通过顶部按钮在居中弹窗中查看项目资产树及设置入口。点击资产后打开居中的详情弹窗；窄屏页面不产生横向滚动。

### 4.1 文件树组织方式

- 「项目 → 资产」：项目下显示资产名称；点击资产打开详情弹窗。
- 「项目 → 对话」：项目下显示与该项目有关的对话。每个对话节点包含生成、上传和引用的资产；同一资产可出现在多个对话节点的结果中。未关联对话的资产归入「无来源对话」。
- 「项目 → 分类」：项目下显示该项目的分类及「未分类」，节点数量统计归属该分类的资产。
- 「项目 → 格式」：项目下按已核验的文件格式分组，无法确认格式的资产归入「未知格式」。
- 「项目 → 评分」：按 5 星至 1 星及「未评分」分组，点击后使用精确评分筛选。
- 「项目 → 标签」：项目下显示当前项目资产使用的标签及「无标签」；一个资产可计入多个标签节点。

点击分组节点，在右侧展示该组资产，并在列表上方显示可清除的节点条件。分组数量统计不同的项目资产条目，同一分组中不重复计数。分组条件与右侧筛选共同作用；点击项目节点可清除分组条件并查看该项目全部资产。设置按钮中的组织方式由用户选择，离开资产库后再次进入时保持上次选择。

## 5. 资产基本信息

基本信息固定显示「评分、尺寸、文件大小、格式、添加日期、创建日期、修改日期」。评分与添加日期来自当前项目的资产条目；创建日期按资产来源读取；文件属性与修改日期对应条目固定的版本。无可用数据时显示「—」，不猜测数值。

### 5.1 评分

- 范围为 0–5 星，0 表示未评分。评分属于当前项目的资产条目，与文件版本分开。同一文件在其他项目可有不同评分。
- 在详情区点击星级直接保存；点击已选星级可清除评分。键盘和读屏可以识别「评分 1 星」至「评分 5 星」及「清除评分」。
- 保存失败时恢复原评分，在评分位置显示「评分保存失败」和「重试」。

### 5.2 尺寸、文件大小与格式

- 图片显示宽 × 高，单位为像素。视频在可靠取得画面尺寸时使用同一格式。文档、音频和未取得尺寸的文件显示「—」。
- 文件大小使用所选 AssetVersion 的字节数。界面按 1024 进位显示 B、KB、MB 或 GB；悬停或聚焦时可查看原始字节数。
- 格式依据服务端核验后的 MIME 类型显示常见简称，例如 PNG、JPEG、MP4、PDF。无法识别时显示 MIME 类型；名称扩展名与文件内容不一致时，以核验后的文件类型为准。
- 文件版本保存核验后的 MIME 类型及规范化格式值。格式下拉选择显示当前项目实际存在的格式与「全部格式」；选择格式后与资产类型、分类及其他条件共同筛选。无法确定的文件归入「未知格式」。项目资产树的「格式」视图使用同一格式值和数量。
- 尺寸属于 AssetVersion。上传、Studio 生成和工作流产出的图片使用同一套信息提取规则；读取失败保留空值。

### 5.3 三个日期

- 「添加日期」取资产进入当前项目资产库的时间。Session 新产物取资产及项目条目写入时间；跨项目引用取加入目标项目的时间。移动分类、修改标签或评分均不改变该时间。
- 「创建日期」按当前版本的来源确定。Pixoma 中创建的文档、模型生成内容和工作流产物，取资产首次创建时间。上传的外部文件仅在来源提供原文件创建时间时显示该时间。
- 「修改日期」按当前版本的来源确定。上传且未经 Pixoma 编辑的文件，取来源提供的原文件修改时间；在 Pixoma 编辑或重新生成的版本，取该版本生成时间。
- 浏览器上传可提供 File.lastModified，无法可靠提供原文件创建时间。上传文件没有创建时间时显示「—」。无时区信息的来源日期也不能推算成精确时刻。
- 日期在界面使用当前浏览器时区，格式为 YYYY/MM/DD HH:mm；完整时间可在悬停或聚焦时查看。源数据保留原始时间与来源标识。
- 项目资产条目固定旧版本时，尺寸、大小、格式及修改日期继续对应旧版本。评分、标签和分类仍对应当前项目的条目。
- 按最近修改排序时，缺少修改日期的资产排在有日期的资产之后。修改日期范围筛选不包含缺少日期的资产。

### 5.4 图片与视频调色盘

- 图片和视频在文件版本保存后异步分析调色盘。图片统计可见像素，忽略透明区域；视频只分析开头 10 秒，最多抽取 4 帧并综合统计颜色，短视频使用实际可取得的画面。分析任务限制读取量和处理时间，不随视频总时长增加采样范围。解码失败时保留文件与其他元数据，并显示调色盘分析失败状态。
- 每个 `AssetVersion` 记录最多 10 个代表色，按画面占比排列；每项保存 HEX 色值。视频取样时点、分析状态与分析时间随结果保存。重新分析同一版本只更新该版本的调色盘结果，不改动文件内容。
- 详情弹窗在「基本信息」后显示横向圆形色块，排列方式参考用户提供的 Eagle 截图。悬停或聚焦色块可查看 HEX 色值。分析中显示「正在分析调色盘…」；失败时显示「调色盘分析失败」和「重新分析」。音频和文档不显示调色盘区。
- 当前项目条目更新固定版本后，详情展示新版本的调色盘；其他项目条目和历史 Session 引用继续展示各自所指版本的结果。

## 6. 来源与版本

详情弹窗展示所属项目、来源类型、来源 Session、来源操作和固定版本号。来源 Session 可访问时提供「打开来源对话」；来源信息不可读取时保留来源快照与固定版本号，并显示「来源对话暂不可用」。

「打开原文件」用于浏览器预览。「导出」下载当前项目条目的固定版本，保留安全处理后的文件名及扩展名。来源 Session 后续生成的新版本不会改变已有项目条目的预览和导出内容。

版本区可查看来源资产的历史版本。查看历史版本只改变当次预览；「更新项目资产版本」经确认后，只改变当前项目条目的固定版本。其他项目条目及历史 Session 引用保持原版本 ID。详情弹窗提供「用于创作」，可选择当前项目的已有 Session 或新建 Session；选择其他项目时，目标项目同时获得对应条目。

## 7. 分类与名称

- 分类属于一个项目范围，支持多级创建、改名和移动。分类名称在同一项目的同一上级内不可重复；名称去除首尾空白后不能为空。
- 顶部分类栏选择分类后显示本分类及子分类的资产。多级分类可从对应选项的下级菜单选择；分类栏可横向移动。每个项目资产条目只有一个所属分类；「未分类」收纳当前项目中没有所属分类的资产。
- 资产详情和批量工具均可把资产移动到分类。分类选择器展示层级，并支持按名称搜索。目标分类不可用时保留原分类，并提示「移动资产失败」。
- 删除分类时，弹窗明确列出受影响的资产及子分类数量。确认后把直接归属的资产和子分类移至上一级；无法通过名称唯一性校验时，阻止删除并指出冲突分类。
- 项目资产条目允许设置展示名称。详情弹窗中的名称旁提供「重命名」入口，编辑时显示输入框、「保存名称」和「取消」；提交时去除首尾空白，空名称显示字段错误。改名只改变当前项目的展示名称，其他项目、来源 Session 和历史消息保留原名称。搜索同时覆盖展示名称与原名称。
- 分类栏中选中自建分类后提供「重命名分类」入口，使用居中弹窗编辑。名称去除首尾空白；同一上级存在同名分类时，保留弹窗并显示「分类名称已存在」。保存后同步更新分类栏、资产所属分类、筛选条件和移动分类选择器。
- 同一资产再次用于同一项目时复用已有条目；需要更换其固定版本时通过「更新项目资产版本」确认，添加日期、展示名称、标签及评分保持原值。

## 8. 标签与评分管理

- 同一账号内同名标签共用一个标签条目。输入标签后可选已有标签或创建新标签；标签去除首尾空白，重复标签只保留一项。
- 标签关系属于项目资产条目。修改标签不会产生新的 AssetVersion，也不会影响其他项目或引用该文件的 Session。
- 详情区直接添加、移除标签。批量操作可给所选资产添加标签、移除标签或设置统一评分。
- 标签和评分保存成功后，列表、详情和筛选结果使用同一份新数据；失败时恢复操作前的数据并提供重试。

## 9. 搜索、筛选与排序

- 搜索框搜索当前项目内的展示名称、原名称和标签。点击左侧项目节点后切换搜索范围。
- 资产类型使用单选下拉选择：全部、图片、视频、音频、文档、其他。格式使用独立下拉选择，仅列出当前项目存在的格式和「全部格式」。顶部分类栏使用单行 FilterSegment 展示当前项目分类。
- 「筛选」Popover 提供来源 Session、标签、最低评分、格式、尺寸范围、文件大小范围、添加日期范围、归档状态和「重复文件」条件。已生效条件以紧凑标记显示，可单项清除，也可「清除筛选」。
- 格式下拉选择单项精确匹配规范化格式值；多个标签要求资产包含全部已选标签。不同类条件同时满足。分类、资产类型、格式、搜索和其他筛选共同作用。
- 排序提供最近添加、最早添加、最近修改、名称、文件大小和评分。默认最近添加。相同排序值继续按资产库记录 ID 排列，使翻页结果稳定。
- 在左侧树中选择其他项目、分组节点，或修改搜索、筛选、分类、格式、排序时，从第一页读取新结果并清空当前选择。列表总数反映当前全部条件；切换项目时清除原项目的分类、格式及来源对话条件。
- 网格和列表共用查询结果。切换视图保留分类、搜索、筛选和排序。

## 10. 批量整理与导出

- 资产卡片和列表行提供选择控件。工具栏明确显示已选数量，「全选当前页」只选择当前页显示的资产。
- 批量工具提供移动分类、添加标签、移除标签、设置评分、添加到其他项目、归档、恢复和导出。全部成功后刷新列表；部分失败时列出失败资产并保留这些资产的选择。
- 单个资产「导出」下载原文件。多个资产「导出」生成 ZIP；名称重复时增加序号，避免覆盖。压缩包内只包含当前选中的固定版本。
- 「添加到其他项目」为目标项目建立资产条目，不复制文件；已存在的条目保持目标项目当前的展示名称、分类、标签、评分和固定版本。
- 「归档」使资产退出当前项目的默认列表，仍保留在「已归档」筛选结果及来源 Session 中，可随时恢复。归档项目条目不影响其他项目条目和历史引用。
- 所有跨项目操作、导出和归档操作继续校验账号权限。下载地址不能使其他账号读取资产。

## 11. 重复文件提示

- 根据文件内容的 SHA-256 识别完全相同的 AssetVersion，只在当前账号内比较。项目视图优先显示本项目中的相同文件，并可查看其他项目中可访问的同组资产。
- 上传或生成后若已有相同内容，显示「发现相同文件」及已有资产入口。创作者可保留当前资产或归档当前项目条目；系统不自动合并名称、标签、来源或版本。
- 「重复文件」筛选只返回存在相同内容的资产，并可查看同组资产。内容哈希读取失败的文件不标记为重复。
- 归档重复资产不影响历史 Session 所引用的版本。

## 12. 页面与交互

### 12.1 资产浏览

从 Studio 通用入口进入时选中最近查看的项目；首次进入时选中项目列表中的首个项目，没有已创建项目时选中「未归属项目」。从项目或 Session 入口进入时选中对应项目，Session 入口同时应用来源对话筛选。左侧项目资产树按项目名称排列，「未归属项目」位于末尾；项目下资产按最近添加排列。点击项目节点切换右侧资产列表，展开和收起操作独立；点击资产节点、资产卡片或列表行打开详情弹窗。选择控件只负责批量选择。关闭详情弹窗后，保持项目、资产树展开状态、分类、搜索、筛选、排序和滚动位置。

详情弹窗宽屏时占用视口主要区域，左侧资产预览约占三分之二，右侧信息约占三分之一并单独滚动；窄屏时预览位于信息上方。左侧提供「放大预览」按钮，点击后资产预览占用整个弹窗内容区域，按钮变为「恢复布局」。放大状态下关闭弹窗或打开其他资产后恢复左右布局。「基本信息」默认展开，评分位于首行；标签、来源和版本分别成组。大图保持完整预览，长文件名换行，数值使用等宽数字。

Session 中的生成结果、手动文档和上传文件保存成功后，自动出现在所属项目的资产列表及左侧资产树。Session 资产面板提供「查看项目资产」入口，选中所属项目并筛选该 Session 的资产；原「存入资产库」操作移除。资产库上传文件时使用当前选中的项目。上传成功后选中新资产；文件信息仍在读取时显示加载状态。发现相同文件时，在新资产详情弹窗展示已有资产入口。

### 12.2 搜索与分类

输入搜索内容后更新当前项目的资产列表。切换分类、筛选条件或排序时保留搜索词；切换项目时清除搜索词。空结果显示「没有匹配的资产」和「清除筛选」；当前项目没有任何文件时显示「当前项目暂无资产」和「上传资产」。

项目资产树支持键盘展开、收起和选择；项目节点、资产节点与分组节点有不同的可访问名称。树标题旁的设置按钮通过单选菜单切换六种组织方式。选择对话、分类、格式、评分或标签节点后，右侧显示对应资产与可清除的节点条件；切换组织方式清除节点条件。分类栏位于筛选区底部，支持键盘选择及横向移动；分类属于当前项目。移动分类可以在详情弹窗或批量工具中通过同一分类选择器操作；触屏不依赖拖动。

### 12.3 批量操作

选择资产后，资产区顶部切换为批量工具栏。关闭选择状态清空选择；切换项目或修改搜索、分类、筛选时也清空选择。操作中禁用重复提交，成功后刷新受影响的结果、资产树和详情。批量操作处理当前项目中的资产条目。

### 12.4 导出与归档

导出开始后展示「导出中…」，浏览器接管下载时退出等待状态。生成压缩包失败时显示「导出失败」和「重试导出」。批量归档前明确显示受影响的项目条目数量；恢复后回到原项目分类。

### 12.5 关键界面文案

- 搜索框：「搜索名称或标签」。
- 项目入口：左侧项目资产树中的项目节点与「未归属项目」节点。
- 文件树设置：「项目 → 资产」「项目 → 对话」「项目 → 分类」「项目 → 格式」「项目 → 评分」「项目 → 标签」。
- 资产类型：「全部」「图片」「视频」「音频」「文档」「其他」；格式：「全部格式」及当前项目存在的格式，均以下拉选择展示。
- 分类入口：「全部资产」「未分类」「新建分类」。
- 详情操作：「用于创作」「打开来源对话」「打开原文件」「导出」「移动到分类」「添加到其他项目」「更新项目资产版本」。
- 批量操作：「全选当前页」「移动到分类」「添加标签」「移除标签」「设置评分」「添加到其他项目」「归档」「恢复」「导出」。
- 信息缺失显示「—」；保存、上传、导出和读取失败时，错误内容点明操作对象，并提供重试入口。

## 13. 视觉与可访问性

- 使用 Pixoma 语义颜色和现有 shadcn/ui 组件。页面主体使用内容表面色，内部信息组使用次级表面色，只有浮层使用阴影。
- 同一区域只保留一个主操作；其他操作使用次级按钮。资产、分类及操作图标沿用后台图标清单。
- 搜索框、资产类型及格式下拉选择、分类 FilterSegment 和筛选 Popover 保持紧凑；不增加多行常驻筛选表单。
- 桌面端项目资产树保持左侧固定，树内独立滚动；窄屏时通过按钮打开居中弹窗。详情与项目资产树弹窗保持居中，不出现页面级横向滚动。触屏控件的可点区域至少 44px。
- 卡片、评分、分类、筛选、批量选择及弹窗均提供键盘操作、可见聚焦环和可访问名称。减少动态效果的系统设置生效。
- 加载、空结果、读取失败、保存失败、导出失败和无权限状态都有明确反馈与恢复入口。

## 14. 数据与接口要求

- `Asset` 保留账号、内容身份、创建来源和创建时间；`AssetVersion` 保留不可变的版本 ID、MIME 类型、字节数、Blob 引用和来源时间。文件信息记录保存核验后的规范化格式、图片宽高和内容哈希；这些衍生字段允许为空。图片与视频版本另存调色盘状态、最多 10 个 HEX 色值、分析时间和视频取样时点。
- `ProjectAsset` 使用账号、项目范围和 Asset ID 保证每个项目中同一资产只有一个条目。「未归属项目」使用可参与唯一性校验的明确范围值。条目保存固定版本 ID、展示名称、分类、评分、添加时间、归档状态和标签关系；评分范围为 0–5。
- `AssetCategory` 属于项目范围，同一项目的同一上级中名称唯一。项目资产条目引用的分类必须属于同一项目。
- `SessionAssetUsage` 保存账号、Session、Asset、AssetVersion、来源或引用用途及产生操作，同时保存来源名称与操作时间快照。来源 Session 的项目变化不会修改已存在的固定版本引用；Session 被删除后仍可显示来源快照。
- 生成、手动创建和 Session 上传在同一数据库事务中保存 Asset、AssetVersion、项目资产条目及 Session 来源关系。重试使用稳定的产生操作 ID 防止重复条目。Blob 写入后如数据库事务失败，清理该操作独占且未被引用的 Blob。
- 图片尺寸至少覆盖 PNG、JPEG、GIF 和 WebP。SVG 只有在文件明确提供可解析尺寸时显示宽高。
- 列表接口接受项目范围、来源 Session、分类、规范化格式和筛选条件，一次返回项目资产条目、固定版本信息与总数。筛选、排序和分页由服务端处理。项目资产树按项目读取未归档资产数量，并按所选组织方式返回分组名称与数量；对话分组以 `SessionAssetUsage` 为依据，展开项目时分段读取资产或分组节点。详情读取当前账号可访问的来源、版本及调色盘信息。
- 更新固定版本、修改分类、标签、评分及展示名称时，服务端校验账号、项目和版本归属。重复提交不能产生重复的项目条目、来源关系或标签关系。跨项目添加资产时只复用文件版本，不复制 Blob。
- 文件信息分析只更新关联的衍生信息，不改写 AssetVersion 的内容身份或 Blob。分析失败不阻止查看和导出原文件。批量写入返回每项结果；失败资产可重试，成功资产的状态保持已保存。

### 14.1 数据结构启用

- 启用项目资产库时重建受本次调整影响的 Studio 资产与对话数据，采用新的项目资产条目、来源关系和分类结构。其他业务数据保持原状。
- 正常服务只读写新的数据结构，不保留旧资产库接口、双写、旧字段判断或运行时数据转换。具体表结构、重建范围和执行顺序见技术方案。

## 15. 验收标准

1. 任一项目 Session 生成图片后，图片无需手动保存即可在该项目资产库和来源 Session 资产面板中出现，二者指向同一 Asset ID 与 AssetVersion ID。
2. 无项目 Session 生成的资产进入「未归属项目」；从资产库直接上传时，资产进入用户选择的项目范围。
3. 把 Session 移到另一项目后，目标项目可找到该 Session 创建的资产，原项目条目与原有整理信息保留。
4. 在另一个项目使用资产后，目标项目获得条目且不复制 Blob；两个项目独立修改名称、分类、标签和评分。
5. 删除项目后，其 Session 与资产可以在「未归属项目」找到；原分类层级、来源和固定版本仍可读取。删除 Session 后资产仍可预览和导出。
6. 上传 PNG 后，详情显示与文件一致的尺寸、大小和格式；添加日期取资产进入当前项目的时间。浏览器未提供原文件创建时间时，创建日期显示「—」。
7. Pixoma 生成资产显示自身创建时间及固定版本生成时间。来源产生新版本后，既有项目条目的文件信息保持原值，直到用户确认更新其固定版本。
8. 项目、来源 Session、分类、标签、评分、搜索、筛选、排序与分页同时使用时，列表和总数一致。
9. 分类改名、移动和删除后，资产保留，分类层级及数量正确；不同项目可以使用相同分类名称。
10. 批量操作只处理所选项目资产条目。部分失败时能识别失败资产并重试。
11. 单项导出和 ZIP 导出只包含所选条目的固定版本，名称重复的文件不会互相覆盖。
12. 内容完全相同的文件出现重复提示；内容不同的文件不进入同一重复组。
13. 归档项目资产后，默认列表不再显示该条目；「已归档」筛选仍能找到并恢复，来源 Session 和其他项目引用保持可用。
14. 账号之间无法读取、修改、导出或通过重复提示发现彼此的资产；项目 ID 不属于当前账号时不能读取项目资产。
15. 桌面、窄屏、键盘和触屏均可使用项目资产树选中项目与资产、查看详情、设置评分、筛选及导出。
16. Studio 通用入口选中最近查看的项目；项目及 Session 入口选中对应项目，Session 入口同时应用来源对话筛选。
17. 分类栏占据原资产类型切换位置，资产类型通过下拉选择筛选；切换项目后只展示该项目的分类。
18. 缺失元数据、来源 Session 不可用和请求失败时，页面不显示推测数值，并提供对应反馈。
19. 从资产库点击「用于创作」后，目标 Session 引用操作时选中的固定版本；跨项目使用时目标项目建立对应条目。
20. 更新当前项目条目的固定版本后，新引入的 Session 使用新版本，历史 Session 和其他项目条目仍使用原版本。
21. 新数据结构启用后，资产只通过项目资产条目查询，Session 面板与资产库显示相同的 Asset ID 和 AssetVersion ID。
22. 上传或生成 PNG、JPEG、MP4 后，规范化格式写入所选固定版本；格式下拉选择与文件树「格式」视图返回相同的格式和数量，扩展名与文件内容不一致时以核验结果为准。
23. 图片生成或上传后得到代表色；视频只从开头 10 秒内最多 4 个有效画面取样。详情展示最多 10 个色块，色值与所选固定版本对应；音频和文档不显示调色盘。
24. 调色盘分析中、分析失败和重新分析均有明确状态。分析失败不影响资产查看、筛选及导出；更新固定版本后，详情展示新版本的调色盘。
25. 设置按钮可在六种文件树组织方式之间切换，切换后保留当前项目与展开状态；分组节点正确筛选右侧资产，清除节点条件后恢复当前项目结果。
26. 「项目 → 对话」显示生成、上传及引用该资产的对话；同一资产关联多个对话时可以从各对话找到，项目结果和计数按不同项目资产条目统计。
